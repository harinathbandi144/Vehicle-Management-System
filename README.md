# Vehicle Management System

A console-based **Vehicle Management System** built using **Core Java and Object-Oriented Programming (OOP)**.

This project was developed as a hands-on learning project to understand how Java concepts work together in a real-world application.

---

## Project Overview

The Vehicle Management System simulates the basic operations of an automobile workshop.

The system manages:

- Customers
- Vehicles
- Service Jobs
- Mechanics
- Service Types
- Service Status
- Bills
- Payments

The main goal of this project is to apply Core Java concepts through an actual business domain instead of learning each concept in isolation.
